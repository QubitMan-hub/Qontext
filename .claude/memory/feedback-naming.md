Name each product and feature in the spirit of the rest: a quantum idea or an art-studio word (Janus, Fringe,
Bouncer, Wall Wash, Thresholds, Phase dial). Wherever the name appears in UI, pair it with a plain descriptor.
The full list lives in README.md and in the qontext-builder skill.

**Why:** the owner asked for "insane naming conventions for all our products", explained in plain words.

**How to apply:** before shipping anything new, pick its name, add it to the README names table, and use it
the same way in code comments, docs, captions and UI.
