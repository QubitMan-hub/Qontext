---
name: feedback-writing-style
description: How Qontext copy, docs and replies are written (short, human, no em dashes)
type: feedback
---

Write short, plain, human sentences. No em dashes, no unnecessary dashes or emojis. Prefer inline subheadings
to standalone headers, and keep formatting minimal.

**Why:** the owner's standing preference for everything written for them.

**How to apply:** site and Atelier copy, captions in the film, README and changelog entries, commit messages
and replies to the owner.
