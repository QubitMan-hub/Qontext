# The Qontext Film Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A narrated, captioned film of about 2:45 that explains every Qontext product, rendered with Remotion from engine-drawn scenes and real clips, replacing `dist/media/qontext-film.mp4`.

**Architecture:** `film/` is a Remotion project with its own pinned dependencies. One script file is the source of truth for narration and captions. `align.mjs` turns the voice track's pauses into `timing.json`. Each scene is a React component that draws with `src/engine`, and two scenes use clips recorded by `clips.py`. A root `npm run film` runs the whole pipeline into `dist/media`.

**Tech Stack:** Remotion 4.0.534, React 19.2.3, TypeScript, node:test, ffmpeg (from Playwright's install), Playwright (Python) for clips.

**Spec:** `docs/superpowers/specs/2026-10-12-film-design.md` (approved 2026-10-12: Alex voice, about 2.5 min, easy everyday slang, animation plus real clips; 4 takes generated).

## Global Constraints

- Narration and captions are the same sentences, from `film/src/script.json`. No digits, no maths symbols, no em dashes.
- 1920 by 1080, 30 fps, H.264 MP4. Fixed world seeds per scene: a re-render is identical.
- Colors come from the engine or the site tokens. Fonts are Anybody (names, captions) and Literata (a few on-screen words), loaded from local files.
- Remotion renders with `--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell` when that file exists.
- Motion: snap and settle, no bounce; split tiles mean undecided.

## Review Focus

- A voice take whose pauses don't match the sentences: the alignment falls back to proportional timing and says so; the film still renders.
- No voice file yet: the film renders with estimated timing (about 165 words a minute) and silent audio, so scenes can be built and checked first.
- Long captions: a sentence never wraps past two lines at 1920 by 1080.
- Fonts not ready at render time: frames wait for them (`delayRender`), so no frame shows a fallback face.
- The site's chapter list follows `film-chapters.json`, so ten chapters appear and seeking works.

**Files:** create `film/package.json`, `film/remotion.config.ts`, `film/tsconfig.json`, `film/src/index.ts`, `film/src/Root.tsx`, `film/src/Film.tsx`, `film/src/script.json`, `film/src/timing.ts`, `film/src/Captions.tsx`, `film/src/theme.ts`, `film/tests/script.test.mjs`. Modify `.gitignore` (`film/node_modules`, `film/out`).

**Interfaces:**
- Produces: `script.json` = `{ scenes: [{ id, chapter, sentences: string[] }] }` with the ten scenes and the exact sentences from the spec. `timing.json` = `{ source: 'voice'|'estimate', durationMs, scenes: [{ id, startMs, endMs, sentences: [{ text, startMs, endMs }] }] }`. `estimateTiming(script, wpm = 165) -> timing`. `<Captions timing />` shows the sentence active at the current frame.

- [ ] Test: `script.json` has ten scenes; ids `hook idea dare world rooms phase atelier observer probe outro`; no digits, `=+×÷^%<>` or em dashes; its sentences joined equal the spec's narration lines.
- [ ] Test: `estimateTiming` is ordered and gap-free, and every sentence has `endMs > startMs`.
- [ ] Implement, `npx remotion still Film --frame=60` renders, commit.

### Task 2: Voice alignment

**Files:** create `film/scripts/align.mjs` (exports `alignToPauses(sentences, pauses, durationMs)`, CLI writes `film/src/timing.json` from `film/public/voice.mp3` via `ffmpeg -af silencedetect=noise=-35dB:d=0.25`), `film/tests/align.test.mjs`.

- [ ] Tests: with exactly `sentences.length - 1` pauses, sentence starts are the pause ends in order; with pauses longer than 0.6 s marking scenes, scene starts match; with one missing or one extra pause, it falls back to word-share timing within the voice length and returns `source: 'estimate-in-voice'`.
- [ ] Implement, commit.

### Task 3: Engine-drawn scenes

**Files:** create `film/src/scenes/{Hook,Idea,Dare,Rooms,PhaseDial,ObserverSuperpose,ProbeNotary,Outro}.tsx` and `film/src/parts/` for shared pieces (`Tile`, `Grid`, `Frame`, `Moon`).

**Interfaces:** each scene is `({ scene, fps }) => JSX` placed by `Film.tsx` in a `<Sequence from={startFrame} durationInFrames={...}>`. All colors come from the engine: `collapse`, `tileColor`, `interfere`, `kcbsProbs`/`pentaColors`, `samplePair`, `analyzeShape`/`drawShape`, `phaseTheme`.

- [ ] Each scene draws what the spec describes for it. Sentences that name a thing switch the visual to it at that sentence's start.
- [ ] Contact sheet: stills at the middle of every scene, checked for overflow and readability. Fix in one batch.
- [ ] Commit.
