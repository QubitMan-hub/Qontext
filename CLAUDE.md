# Qontext

A contextual color engine built on quantum contextuality: the engine, the website, the Atelier (studio),
Observer (runtime), Superpose (Figma plugin) and Probe (hardware CLI). Start with README.md for the names
and commands, and docs/ARCHITECTURE.md for how the pieces fit.

Before calling anything done: `npm run check`, `python3 -m pytest tests/e2e -q -p no:playwright`,
`ruff check python scripts tests`, and screenshots at 1440x900 and 390x844 in light and dark.
